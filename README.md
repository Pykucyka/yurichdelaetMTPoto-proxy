# 🚀 MTProto Proxy Installer with Fake TLS & Interactive TUI

**Профессиональный скрипт для развёртывания MTProto прокси на VPS за 2 минуты.**  
Поддерживает маскировку под HTTPS (Fake TLS), автоматическую установку Docker, открытие портов, а также **интерактивное меню управления** с выводом статистики, логов и возможностью обновления.

👉 **Репозиторий:** [[github.com/yurichdelaet/mtproto-proxy](https://github.com/Pykucyka/yurichdelaetMTPoto-proxy)]

---

## ✨ Ключевые возможности

| Функция | Описание |
|---------|----------|
| **Fake TLS** | Трафик маскируется под безопасное соединение с `cloudflare.com` (или любым другим доменом) |
| **Одна команда** | Всё, что нужно – запустить скрипт и ввести порт (или оставить по умолчанию) |
| **Автоматическая установка Docker** | Если Docker не установлен, скрипт сам скачает и настроит его |
| **Глобальная команда `yurich`** | После установки управляй прокси из любой точки: `sudo yurich` |
| **Интерактивное TUI-меню** | Статистика, информация о прокси, логи, переустановка, обновление скрипта – всё в красивом интерфейсе |
| **Веб-статистика** | Прокси имеет встроенный веб-интерфейс на порту `8080` (можно смотреть количество подключений) |
| **Поддержка TON** | Вы можете поддержать автора, отправив donation на TON-кошелёк (см. раздел "Поддержать проект") |

---

## 📦 Требования

- VPS с **Ubuntu 20.04 / 22.04 / Debian 11+** (или CentOS 7+)
- Минимум **512 MB RAM**, 1 ядро CPU
- Открытый порт (по умолчанию `8443`) в настройках облачного провайдера

## 🚀 Быстрая установка (одна команда)

Выполните на сервере от **root**:

```bash
bash <(curl -s https://raw.githubusercontent.com/Pykucyka/yurichdelaetMTPoto-proxy/main/mtp.sh)
Если curl не установлен:

bash
apt update && apt install curl -y
После успешной установки скрипт покажет секрет (32 символа + ee + домен) и готовую ссылку tg://proxy?....

🕹️ Управление прокси: глобальная команда sudo yurich
После установки в системе появляется команда yurich. Запустите её с правами root:

bash
sudo yurich
Вы увидите интерактивное меню:

text
╔════════════════════════════════════════════════════════════╗
║                    📋 МЕНЮ УПРАВЛЕНИЯ                      ║
╚════════════════════════════════════════════════════════════╝

   1 ─ 📊 Статистика прокси (нагрузка, подключения)
   2 ─ ℹ️  Информация о прокси (секрет, ссылка)
   3 ─ 🔄 Обновить скрипт до актуального коммита
   4 ─ 🔁 Переустановить прокси (сохраняя секрет)
   5 ─ 📜 Просмотр последних логов
   6 ─ ♻️  Перезапустить прокси-контейнер
   0 ─ 🚪 Выход
Статистика – показывает загрузку CPU, RAM, сетевой трафик и количество активных TCP-соединений.

Информация о прокси – выводит IP, порт, домен маскировки, полный секрет и ссылку для Telegram.

Обновить скрипт – автоматически подтягивает последнюю версию из GitHub (если репозиторий клонирован).

Переустановить прокси – пересоздаёт контейнер, сохраняя секрет (полезно при сбоях).

Логи – показывает последние 50 строк логов контейнера.

Перезапуск – перезапускает прокси-контейнер.

В обычной командной строке (не в меню) вы по-прежнему можете вводить любые команды – меню не мешает.

🤖 Регистрация прокси в Telegram (для статистики)
Чтобы видеть количество активных сессий и TAG, зарегистрируйте прокси в официальном боте:

Откройте @MTProxybot.

Отправьте команду /newproxy.

Введите IP вашего сервера и порт (например, 8443).

Вставьте ПОЛНЫЙ секрет – ту длинную строку, которая начинается с ee... (скопируйте её из вывода установки или из пункта меню 2).

Бот выдаст TAG – сохраните его (он не обязателен для работы, но может пригодиться).

После этого вы сможете смотреть статистику вашего прокси через бота.

📊 Просмотр статистики в реальном времени
Через TUI-меню
Выберите пункт 1 – увидите docker stats и количество активных подключений.

Через веб-интерфейс
Прокси имеет встроенную веб-панель статистики. Откройте в браузере:

text
http://IP-вашего-сервера:8080
Вы увидите информацию о количестве подключений, версии прокси и другую полезную статистику.

Через команды Docker
bash
docker logs -f mtproxy      # Потоковая печать логов
docker stats mtproxy        # Живая статистика CPU/RAM
docker exec mtproxy ss -tun # Список активных соединений
💾 Сохранение и восстановление секрета
При переустановке прокси (пункт меню 4) скрипт автоматически сохранит ваш текущий секрет, если контейнер ещё существует.
Если вы хотите сохранить секрет вручную, просто скопируйте его в надёжное место. Без секрета вы не сможете подключиться к своему же прокси.

🛠 Управление Docker (для продвинутых)
Действие	Команда
Остановить прокси	docker stop mtproxy
Запустить прокси	docker start mtproxy
Перезапустить	docker restart mtproxy
Посмотреть логи	docker logs -f mtproxy
Удалить прокси	docker rm -f mtproxy
❓ Частые вопросы
Почему секрет длинный (больше 32 символов)?
Потому что используется Fake TLS. Секрет состоит из:
ee (включение Fake TLS) + 32 случайных hex-символа + домен в hex-кодировке.
Именно такой секрет нужно вставлять в @MTProxybot – бот отлично его принимает.

Что делать, если прокси не подключается?
Проверьте, открыт ли порт в облачном фаерволе провайдера (не только в UFW на сервере).

Убедитесь, что Docker-контейнер запущен: docker ps | grep mtproxy.

Посмотрите логи: docker logs mtproxy.

Перезапустите прокси через меню или командой docker restart mtproxy.

Как обновить сам скрипт?
Выполните sudo yurich → выберите пункт 3 (Обновить скрипт). Скрипт сам подтянет последнюю версию из GitHub.

Как полностью удалить прокси?
bash
docker rm -f mtproxy
rm -f /usr/local/bin/yurich
rm -rf /opt/mtproto-proxy
