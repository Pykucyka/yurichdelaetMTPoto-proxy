# 🚀 MTProto Proxy Installer with Telemt (Fake TLS)

**Простой и надёжный скрипт для развёртывания высокопроизводительного MTProto прокси** с поддержкой **Fake TLS** (маскировка под обычный HTTPS) на любом VPS.  
Прокси работает на одном порту (по умолчанию 443) и неотличим от обычного защищённого трафика, что позволяет обходить DPI-блокировки.

👉 **Репозиторий:** [github.com/Pykucyka/yurichdelaetMTPoto-proxy](https://github.com/Pykucyka/yurichdelaetMTPoto-proxy)  
👉 **Поддержать:** TON `UQBPaI8FG9jqxsuPVcdTToJtUqaxVOmST6pFSeB_kMCOe0zO`

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🔒 **Fake TLS** | Трафик маскируется под защищённое соединение с реальным доменом (например, `yandex.ru`) |
| ⚡ **Высокая производительность** | Telemt написан на Rust, потребляет мало ресурсов и выдерживает высокие нагрузки |
| 🐳 **Не требует Docker** | Прокси устанавливается как обычный systemd-сервис, никаких лишних контейнеров |
| 🌐 **Работа на 443 порту** | Единый порт для всех подключений, никаких дополнительных открытий |
| 🖥️ **Глобальная команда `yurich`** | Управляй прокси из любой точки терминала: `sudo yurich` |
| 📊 **Встроенный мониторинг** | Просмотр логов, статуса, статистики и перезапуск через простое меню |
| 📦 **Одна команда установки** | Скрипт сам установит все зависимости и сгенерирует рабочую ссылку |

## 🚀 Быстрая установка

Выполните на сервере (Ubuntu 20.04+, Debian 11+, CentOS 7+) от **root**:

```bash
bash <(curl -s https://raw.githubusercontent.com/Pykucyka/yurichdelaetMTPoto-proxy/main/mtp.sh)
Если curl не установлен:

bash
apt update && apt install curl -y
Скрипт последовательно спросит:

Язык установщика Telemt (русский / английский).

Домен маскировки (например, yandex.ru или 1c.ru). Это домен, под который будет маскироваться трафик.

Порт (рекомендуется 443).

Тип адреса – либо автоматически определённый IP, либо ваш собственный домен (должен быть привязан к серверу).

После установки вы получите готовую ссылку для Telegram вида:

text
tg://proxy?server=ВАШ_IP&port=443&secret=ee...
Нажмите на неё (или вставьте в Telegram) – прокси будет добавлен автоматически.

🕹️ Управление прокси: sudo yurich
После установки в системе появляется глобальная команда yurich. Запустите её с правами root:

bash
sudo yurich
Откроется простое интерактивное меню:

text
=== Управление прокси Telemt ===
1) Посмотреть логи
2) Перезапустить Telemt
3) Остановить Telemt
4) Запустить Telemt
5) Показать статус
6) Показать статистику (netstat)
0) Выход
Логи – просмотр последних событий и ошибок (потоковый режим).

Перезапуск / остановка / запуск – управление сервисом.

Статус – показывает, работает ли прокси и какой порт слушает.

Статистика – отображает активные сетевые подключения к прокси.

Меню не блокирует выполнение других команд – выход осуществляется по нажатию 0.

🤖 Регистрация прокси в @MTProxybot
Чтобы получать статистику использования и TAG (идентификатор) от Telegram, зарегистрируйте прокси в официальном боте:

Откройте @MTProxybot.

Отправьте команду /newproxy.

Введите адрес сервера (IP или домен) и порт (например, 443).

Вставьте полный секрет – длинную строку, начинающуюся с ee..., которую вы получили при установке (или посмотрите через sudo yurich → пункт 2, но её также можно найти в выводе скрипта).

Бот выдаст TAG – сохраните его (он не обязателен, но может пригодиться).

📊 Мониторинг и диагностика
Встроенные команды
journalctl -u telemt -f – просмотр логов в реальном времени.

systemctl status telemt – статус сервиса.

ss -tlnp | grep telemt – список активных соединений.

Проверка работоспособности
Попробуйте подключиться к прокси через Telegram. Если соединение не устанавливается:

Убедитесь, что порт (по умолчанию 443) открыт в облачном фаерволе вашего VPS.

Проверьте локальный фаервол: sudo ufw allow 443/tcp (если используется UFW).

Посмотрите логи: journalctl -u telemt -f – там могут быть ошибки.

Убедитесь, что домен маскировки (например, yandex.ru) реально существует и доступен по HTTPS.

Изменение параметров после установки
Сменить порт – отредактируйте /etc/telemt/config.toml (строка bind = "0.0.0.0:443") и перезапустите сервис.

Сменить домен маскировки – там же измените tls_domain, затем перезапустите прокси и обязательно сгенерируйте новый секрет (он зависит от домена). Проще переустановить прокси заново, но можно и вручную обновить секрет, перезапустив службу.

❓ Часто задаваемые вопросы
Почему прокси не подключается?
➜ Скорее всего, порт 443 закрыт в настройках облачного провайдера. Откройте его для входящих TCP-соединений.
➜ Также проверьте, что домен маскировки доступен (пинг ping yandex.ru).

Как обновить Telemt до последней версии?
➜ Переустановите Telemt командой curl -fsSL https://raw.githubusercontent.com/telemt/telemt/main/install.sh | sh. Скрипт сам обновит бинарный файл и сохранит ваш конфиг.

Можно ли использовать не 443 порт?
➜ Да, при установке можно указать любой другой порт. Однако для лучшей маскировки рекомендуется использовать 443.

Как удалить прокси полностью?

bash
systemctl stop telemt
systemctl disable telemt
rm -rf /etc/telemt /usr/local/bin/telemt /usr/local/bin/yurich
