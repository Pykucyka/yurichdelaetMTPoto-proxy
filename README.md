# 🚀 MTProto Proxy Installer with Fake TLS

**Простой и мощный скрипт для развёртывания MTProto прокси с маскировкой под HTTPS.**  
Обходит блокировки, работает на любом VPS (512 MB RAM), включает интерактивное меню управления.

👉 **Репозиторий:** [github.com/Pykucyka/yurichdelaetMTPoto-proxy](https://github.com/Pykucyka/yurichdelaetMTPoto-proxy)  
👉 **Поддержать:** TON `UQBPaI8FG9jqxsuPVcdTToJtUqaxVOmST6pFSeB_kMCOe0zO`

---

## ❓ Как работает прокси?

**MTProto** – протокол, используемый Telegram для шифрованного обмена сообщениями.  
**Fake TLS** – технология маскировки, которая делает трафик вашего прокси неотличимым от обычного HTTPS-соединения (например, с `cloudflare.com`). Это позволяет обходить системы глубокого анализа пакетов (DPI), которые блокируют обычные MTProto прокси.

**Секрет прокси** имеет специальный формат:  
`ee` (включение Fake TLS) + `32 случайных hex-символа` + `домен маскировки в hex`.  
Именно этот длинный секрет нужно вставлять в бота `@MTProxybot`.

## 🚀 Быстрая установка (одна команда)

Выполните на сервере от **root**:

```bash
bash <(curl -s https://raw.githubusercontent.com/Pykucyka/yurichdelaetMTPoto-proxy/main/mtp.sh)
Если curl не установлен:

bash
apt update && apt install curl -y
После установки вы получите:

Fake TLS секрет (длинная строка)

Telegram-ссылку вида tg://proxy?server=...&port=...&secret=...

Глобальную команду управления sudo yurich

🕹️ Управление прокси (меню)
bash
sudo yurich
Меню содержит следующие пункты:

text
╔════════════════════════════════════════════════════════════╗
║                    📋 МЕНЮ УПРАВЛЕНИЯ                      ║
╚════════════════════════════════════════════════════════════╝

   1 ─ 📊 Статистика прокси
   2 ─ ℹ️  Информация о прокси (секрет, ссылка)
   3 ─ 🌐 Изменить домен/IP для подключения
   4 ─ 🔄 Обновить скрипт до актуальной версии
   5 ─ 🔁 Переустановить прокси (сохраняя секрет)
   6 ─ 📜 Просмотр последних логов
   7 ─ ♻️  Перезапустить прокси-контейнер
   0 ─ 🚪 Выход
Описание пунктов
Статистика – показывает uptime контейнера, загрузку CPU/RAM, сетевой трафик и количество активных TCP-соединений.

Информация – выводит текущий адрес сервера, порт, домен маскировки, полный секрет и готовые ссылки для Telegram.

Изменить домен/IP – позволяет сменить адрес без переустановки. При вводе домена проверяется DNS и выдаётся предупреждение, если запись не указывает на этот сервер.

Обновить скрипт – подтягивает последнюю версию из репозитория GitHub.

Переустановить прокси – удаляет старый контейнер и создаёт новый, сохраняя текущий секрет и порт (полезно при сбоях).

Логи – показывает последние 50 строк логов контейнера.

Перезапустить – перезапускает контейнер (аналогично docker restart mtproxy).

Выход – возвращает в обычную командную строку.

🤖 Регистрация прокси в @MTProxybot
Для получения статистики от Telegram и выдачи TAG (идентификатора) зарегистрируйте прокси в официальном боте:

Откройте @MTProxybot.

Отправьте команду /newproxy.

Введите адрес вашего сервера (IP или домен) и порт (по умолчанию 8443).

Вставьте ПОЛНЫЙ секрет – длинную строку, которую вы получили при установке (начинается с ee).

Бот выдаст TAG – сохраните его (необязательно, но может пригодиться).

После регистрации вы сможете видеть статистику использования прокси (количество активных сессий) через того же бота командой /myproxies.

📊 Статистика и мониторинг
В консоли
Выполните sudo yurich → выберите пункт 1. Вы увидите:

Uptime контейнера (сколько времени работает)

CPU, память, сетевой трафик (как в docker stats)

Количество активных TCP-соединений внутри контейнера

Веб-интерфейс
Откройте в браузере http://IP-вашего-сервера:8080. Там отображается статистика встроенного веб-сервера (количество подключений, версия прокси и т.д.).

Ручные команды
bash
docker logs -f mtproxy      # Поток логов
docker stats mtproxy        # Живая статистика ресурсов
docker exec mtproxy ss -tun # Список активных соединений
⚙️ Оптимизация производительности
Скрипт автоматически применяет улучшенные настройки ядра:

Увеличение буферов приёма/передачи (rmem, wmem)

Включение TCP Fast Open (ускоряет установку соединений)

Отключение медленного старта после простоя

Это особенно важно для больших нагрузок и снижает задержки.

❓ Частые проблемы и их решение
Проблема	Решение
Прокси не подключается	1. Убедитесь, что порт открыт в облачном фаерволе провайдера (не только в UFW).
2. Проверьте логи: docker logs mtproxy.
3. Перезапустите прокси через меню (sudo yurich → пункт 7).
Ошибка: pull access denied	Образ ellermister/mtproxy существует и доступен. Проверьте интернет и DNS на сервере.
Команда yurich не найдена	Переустановите прокси или выполните вручную:
ln -s /opt/mtproto-proxy/mtp.sh /usr/local/bin/yurich
Секрет не подходит для бота	Бот принимает полный секрет (начинается с ee). Скопируйте его целиком из пункта меню 2.
Статистика не обновляется	Убедитесь, что контейнер запущен: docker ps. Если нет – запустите docker start mtproxy.
Веб-интерфейс не открывается	Проверьте, что порт 8080 открыт в firewall и облачных настройках.
🛠 Управление Docker (продвинутый уровень)
Действие	Команда
Остановить прокси	docker stop mtproxy
Запустить прокси	docker start mtproxy
Перезапустить	docker restart mtproxy
Посмотреть логи	docker logs -f mtproxy
Удалить прокси полностью	docker rm -f mtproxy
💾 Ручное сохранение секрета
Если вы хотите сохранить секрет в надёжном месте, выполните:

bash
docker exec mtproxy env | grep SECRET=
Или посмотрите его через меню (sudo yurich → пункт 2).
